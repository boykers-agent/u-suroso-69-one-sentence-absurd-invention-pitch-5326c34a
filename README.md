One sentence pitching an absurd invention.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
A self-folding laundry basket that judges your outfit choices out loud, so you finally wear the good shirt on a Tuesday instead of saving it for a day that never comes.
```
